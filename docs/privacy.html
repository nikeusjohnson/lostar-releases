This website

The website has no account, playlist upload, advertising or analytics functions. It requests release metadata from GitHub to show the current downloads. GitHub and the hosting service process the network information required to serve those requests, such as IP address and browser information. Colour previews and device selections are held in this page only.

App updates

The Android updater checks a public HTTPS release manifest and downloads an APK only when you choose to download it. Update requests do not contain your playlist, provider password or viewing history. GitHub receives ordinary request information. The app checks package identity, version, file size, checksum and certificate before asking the operating system to install. Android performs final signature checks and requests your confirmation.

Your media providers

When you use the app, your configured provider receives requests needed to load or play your content. Optional metadata services receive the title lookups you request. These services have their own privacy policies. LOSTAR does not supply channels or ask you to submit provider credentials to this website.

Local data and backups

Playlists, settings and resume data are stored by the app on your device. Encrypted backup files can contain provider credentials; share them only with people you trust. An in-place signed update is designed to retain local data. Uninstalling an app can remove that data.

Questions and release issues

Use the release repository’s issue tracker for download problems. It is public: do not post playlist links, passwords, access tokens or private viewing information.
