# LOSTAR official downloads

Public APKs, desktop previews, checksums and release notes. App source stays private.

Website: https://nikeusjohnson.github.io/lostar-releases/

Android stable feed: `updates/android-stable.json`. The feed is advanced only after its signed release APK is available. Do not uninstall before updating. The first updater-enabled version needs a manual install.

LOSTAR is a player and does not provide channels or subscriptions. Keep account credentials and playlists out of issues and releases.
